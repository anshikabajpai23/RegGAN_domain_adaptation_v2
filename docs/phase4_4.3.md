## Bucket definition

- **empty**: GT == 0
- **edge**: GT > 0 and within ±1 slice of any span end (span first or last)
- **core**: all other GT > 0 slices

Spans = contiguous runs of GT-nonempty slices, per patient, on `slice_idx`.

