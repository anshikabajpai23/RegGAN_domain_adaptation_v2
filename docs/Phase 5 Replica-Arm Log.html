Phase 5 Replica-Arm Log

DESS → PD meniscus segmentation — experiment log

Phase 5, replica arm

Five novel training-time approaches, each tested as exactly one change against the plain replica recipe (run_v7_replica_seed42) — independent of the crop+sequence checkpoint used elsewhere in this project.

01How to read the numbers below

Dice score
Overlap between the model's predicted meniscus and the human-drawn ground truth, from 0 (no overlap) to 1 (perfect match).
Val real
Dice on the 2 real-patient MRI scans held out for validation during training. Used to pick the "best" checkpoint.
Val fake
Dice on the synthetic (RegGAN-translated) validation scans, from the same training run.
Test 17pt
Dice on 17 real-patient scans held out entirely from training — the most trustworthy number, never seen during model selection.
Best epoch
Which training checkpoint was kept — the one with the highest val-real Dice.
Gap
Train Dice minus val Dice on real PD. A larger gap means more overfitting to the 13 training patients.
±0.0226

Noise floor. Measured by training the exact same replica recipe twice with different random seeds and taking the largest per-patient Dice difference. Any change smaller than this cannot be told apart from ordinary run-to-run randomness — it is the bar every result below is judged against.

02The five approaches

Each targets a different piece of information the base model doesn't explicitly use: where a slice sits in the scan, what the tissue should look like, or how big the meniscus should be.

A3 — Position-weighted loss

up / down

The meniscus is easiest to see mid-scan and hardest right at the slices where it first appears or disappears. This approach makes mistakes on those edge slices count for more (up, weighted up to 2×) or for less (down, weighted down to 0.3×) during training, to see whether emphasizing or de-emphasizing the hard cases helps.

A coding bug in the first attempt (v1) meant the edge-slice weighting wasn't applied at the intended strength. It was corrected in v2, together with a control run (weights left at 1×) so the fix's effect could be isolated from the weighting itself.

E1 — Position as an input channel

position channel

Gives the model one extra piece of information alongside the image: a number from 0 (scan centre) to 1 (outer edge) telling it exactly where this slice sits in the volume, in case that helps it anticipate the expected meniscus shape.

G2 — Rim-darkness prior

intensity loss

Real meniscus tissue is normally darker than the rim of tissue directly around it. This adds a training penalty whenever the model's predicted region doesn't actually look darker than its surroundings, nudging predictions toward physically plausible tissue.

04Conclusion

Of six changes tested against the plain replica baseline, only crop+sequence produced a real improvement.

  • Crop+sequence is the sole run whose test-Dice gain (+0.0277) exceeds the ±0.0226 noise floor — consistent across val real (+0.026), val fake (+0.012), and test (+0.028).
  • All five novel approaches — A3 (both weighting directions), E1, E2, G2, D — land inside the noise floor on test Dice when tested as a single isolated change. None is distinguishable from run-to-run randomness.
  • A3v2-up vs. its own control (A3v2-none) differ by only 0.0001 test Dice — with the v1 loss-normalisation bug fixed, position-weighting the loss has no measurable effect either direction.
  • Validation-set Dice (2 patients) and test-set Dice (17 patients) disagree substantially in places — e.g. E2 has the highest val-real score of any replica-arm run (0.7869) but a below-baseline test score (0.7683) — a reminder that the 2-patient validation set is too small to reliably select checkpoints or judge an idea on its own.
Dice scores computed on the 17-patient held-out test set against manually-traced ground truth. Noise floor measured via seed42-vs-seed7 replication of the replica recipe. All numbers verified directly against saved history.csv training logs and 17-patient inference outputs before inclusion here.
