Naming and Selection Conventions

  • v-numbers: v1-v7 = training recipe versions; v8 = the label for inference on the 17pt cohort (no new training); v9-v12 = Phase 2 loss/aug retrains; v13 = slab (N1); v14 = tear-amodal.
  • Phase 5 arms: run_<idea>_seed42 = crop+sequence arm; run_2_5d_<idea>_seed42 = plain 2.5D (replica) arm; run_fakeonly_<idea>_seed42 = Run 3. lamauto = D with the auto-calibrated weight.
  • Predictions: results/real_pd_predictions_<run>_17pt (healthy test set), results/torn_predictions_<run> (5 held-out torn patients), real_pd_predictions_control_20pt (earlier 20-pt cohort run).
  • Checkpoint selection: replica-recipe runs select ckpt_best.pth on the pooled real-val Dice (vd, 2 val patients); Run 3 selects on fake val only; v14 selects on clean real val (no synthetic tears).
  • Judging threshold: per-patient noise floor 0.0226 (seed 42 vs 7); in Run 3 the seed spread of the mean is 0.0257.
  • Held-out sets: 17pt test (D1 + New) never trained on; 5 torn patients never trained on (v14 script enforces it).

Key Lessons

  • Loss function changes consistently hurt or are neutral on fake PD only — always test with real PD in the loop
  • Background context is required for boundary discrimination — removing it from CE (v9) caused −0.028 drop
  • Post-processing (fill_holes) is neutral on healthy patients — designed for torn/discontinuous meniscus cohort
  • Intensity clipping at 95th percentile (+0.003) — safe, cheap, marginal gain on clean scans
  • clDice (v11) wins the most individual patients (7/17) — best topology-aware loss tried so far
  • v10_boundary severely hurt AC07607B9E5295 (−0.163) — boundary loss is anatomy-dependent
  • Real PD alone from DESS baseline collapses (v5_realPD: 0.135) — always pair with fake PD for warm-start
  • BUT real PD alone from an ImageNet encoder reaches 0.8143 on 17pt (above replica 0.7780 and crop+seq 0.8057) — the pipeline's value has to be re-argued (label efficiency, fewer real patients)
  • Crop + sequence (0.8057) is the only change on the replica recipe confirmed above the 0.0226 noise floor
  • Position-aware ideas (A3, E1, E2, D) and the rim loss (G2) gave no real gain in any arm (crop+seq, plain 2.5D, fake-only)
  • The 17pt test set has been read many times; treat these as exploratory and do one frozen, clean read for the paper
